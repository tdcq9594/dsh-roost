> 截图时鼠标别停在卡片或热力格上——悬停提示（气泡）会被一起截进去，糊在图表上像渲染故障。

README 用标准 Markdown 图片语法引用，GitHub 会按容器宽度自动缩放，不必写死宽度。

以后换图时：

1. 截 dsh-roost 的侧栏面板（「概览」或「权限」页，能一眼看出是 DSH 里的面板，不是 Roost 本体 WebUI）。
2. 比例约 1:1～4:3 之间都行（当前这张是 1.13:1）；PNG / JPG 都行，用 JPG 要同步改 `README.md` 里的引用扩展名。
3. 必须裁掉 DSH 会话列表（含私人会话名）与窗口标题栏；底部别留半截章节或卡片。桌面挂件在右下角露一点没关系。
4. 命名为 `overview.png` 直接覆盖同名文件 —— README 不用改，刷新即生效。
