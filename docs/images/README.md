# 首屏截图

`overview.png` 是 dsh-roost 侧栏「概览」页的截图（2026-11-10，改版后的六格布局）。原图 2219×1219，裁成 **1468×1000（约 3:2，67 KB）**：切掉左侧 DSH 会话列表（含私人会话名）、右侧滚动条与桌面挂件、底部半截的「端口对得上吗」章节和 URL 文字，只留面板里的「现在这样 / 接入进度 / 快捷」三块。

README 用标准 Markdown 图片语法引用，GitHub 会按容器宽度自动缩放，不必写死宽度。

以后换图时：

1. 截 dsh-roost 的侧栏面板（建议「概览」或「能力」页，能一眼看出是 DSH 里的面板，不是 Roost 本体 WebUI）。
2. 建议裁成接近 16:9～3:2；PNG / JPG 都行，用 JPG 要同步改 `README.md` 里的引用扩展名。
3. 别把 DSH 会话列表、桌面挂件、底部 URL 一起截进来；裁完检查没有半截章节或卡片。
4. 命名为 `overview.png` 直接覆盖同名文件 —— README 不用改，刷新即生效。

`docs/` 已包含在 `package.json` 的 `files` 字段里，截图会随 npm 包一起分发，请别放含密钥、openid 或私人聊天内容的图。
