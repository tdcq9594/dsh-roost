# 聊天内切人格指令

> 参考 AstrBot 的 `/persona`，但**没有照搬**——两边的架构不一样，照搬会坏。
> 状态：已实现（`persona.command`，默认关闭）。

## 一、参考了谁

| 项目 | 做法 | 我们拿走了什么 |
|---|---|---|
| **AstrBot 内置指令** | `/persona`、`/persona list`、`/persona <名字>` | 指令形态、`list` 子命令 |
| **astrbot_plugin_persona_plus** | 命令组 `persona_plus`，别名 `pp`；`pp <id>` 快捷切换；`pp switch <id>` 显式切换；`admin_commands` 控制哪些指令要管理员 | 「整段取名字」、`off` 回全局 |
| **同上 · Issue #2** | `/persona my persona` 因按空格切分导致名字匹配失败 | **反例**：名字必须整段取，不能按空格切 |
| **同上 · 关键词自动切换** | `enable_keyword_switching` + `keyword_mappings`（`关键词:人格`），默认开 | **没拿**，理由见 §4 |

## 二、我们的架构差异（决定了哪些不能照搬）

| 维度 | AstrBot / persona_plus | dsh-roost |
|---|---|---|
| 指令框架 | 有：注册指令、权限、会话作用域都由框架给 | **没有**。消息直接进模型一轮，宿主只认「这句话」 |
| 直接发消息 | 有 `send` 通道，指令可以立刻回一条 | **没有**。回复只能走 `qq_send` 工具或正文，且和幂等键绑定 |
| 人格身份 | 人格自带名字、提示词、可用工具 | 名字**全局**（0.11），人格只是「说话方式」 |
| 切换作用域 | 框架的会话/全局，可配置 | `byChat` 落盘（面板切换）；指令用**内存**覆盖，不落盘 |
| 昵称/头像同步 | 支持 NapCat 同步昵称、群名片、头像 | **不做**：名字全局、QQ 资料属于账号，切人格不该改它 |
| 清空上下文 | 可选「切换后清空」 | 不做：会话由 DSH 管理，宿主没有清空接口 |
| 权限默认 | 普通用户可 `switch`/`list`，只有增删改要管理员 | **仅主人**。群里任何人能换人格会直接失控 |

## 三、实现方式

因为我们没有直发通道，指令**不能**在宿主里拦下来回一句。做法是：

1. 消息进来时识别指令（仅主人、`persona.command.enabled`）；
2. 在内存里记下「这个会话临时用 X」（`Map`，不写 `byChat`）；
3. 当轮注入一段 order 909 的提示：`主人刚把这个会话的人格切成「X」，回一句确认即可`；
4. 这一轮照常跑，模型用**新人设**回确认；轮末清掉提示，下一句普通聊天不再带。

好处：不新增发送路径，不会和 `qq_send` 的幂等键打架。
代价：确认语由模型生成，不是固定文案。

### 行为

```
/persona              → 列出可用人格（模型简短列）
/persona list         → 同上
/persona 毒舌群友      → 本会话临时切换
/persona 我的 猫       → 名字带空格也认（整段取）
/persona off          → 回到全局设定
```

匹配顺序：先按 `id`，再按 `label`（显示名）。

### 配置

```jsonc
"persona": {
  "command": { "enabled": false, "prefix": "/persona" }
}
```

- 默认**关**：不开就不会误触发；
- 只对 `owner` 生效；
- 不落盘：进程重启回到全局设定（和 persona_plus 的 `conversation` 作用域一致）。

## 四、为什么不做「关键词自动切换」

persona_plus 默认开着 `keyword_mappings`（消息里出现「女仆」就切）。我们不照搬，原因：

1. **触发面太大**：群里任何人说一句关键词就会切，等于把人格控制权交给所有人；
2. 我们是**单机器人 + 全局名字**的模型，人格是「说话方式」，被随机触发切换比 AstrBot（一人格一身份）更容易让人觉得「她疯了」；
3. 真要做，也应该加「仅主人 + 显式映射表 + 每会话冷却」，那是另一期的事。

## 五、测试

- `parseSwitchCommand` 纯函数：`list`/`off`/带空格名字/不存在/普通聊天；
- 默认配置：`enabled: false`、`prefix: '/persona'`；
- 路由级无法覆盖「一轮模型」，指令的注入路径靠 `order 909` 的静态位置保证。
